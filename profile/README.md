# Lær Smart

**Learn smarter in a world of change.**

Lær Smart AS is a small software company in Oslo, Norway. We build tools that help people learn more effectively, with less noise and more focus.

## 2anki

Our main product. [2anki.net](https://2anki.net) turns your notes into [Anki](https://apps.ankiweb.net/) flashcards, so you remember more for longer. It converts Notion pages, PDFs, Markdown, HTML, CSV and more.

- **Web:** [2anki.net](https://2anki.net)
- **Mac app:** [2anki on the App Store](https://apps.apple.com/app/id6775249373)
- **Source code:** [github.com/2anki](https://github.com/2anki). The server is open source.
- **Claude plugin:** [2anki/claude-plugin](https://github.com/2anki/claude-plugin)

## How we build

- **Built for learning.** Every tool is designed around how people learn, not around features for their own sake.
- **AI where it helps.** We use modern technology to adapt the experience to the learner.
- **Simple and calm.** The technology should recede, so you can focus on what you are learning.
